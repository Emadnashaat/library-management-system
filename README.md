# Library Management System

A Python OOP-based Library Management System for managing books, customers, borrowing orders, inventory, and revenue reports.

## Features

- Add and manage books
- Search for books
- Borrow books
- Handle unavailable quantities
- Manage customers and orders
- Track book inventory
- Calculate order subtotals
- Generate daily revenue reports
- Validate user input
- Handle invalid numeric input

## OOP Concepts Used

- Classes and Objects
- Constructors
- Instance Methods
- `__str__`
- Encapsulation
- Object Interaction

## Python Concepts Used

- Lists
- Tuples
- Sets
- Dictionaries
- Loops
- Conditions
- Functions and Methods
- Exception Handling
- `datetime`
- f-Strings
